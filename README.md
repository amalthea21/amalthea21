## projects

### [pigment](https://codeberg.org/amalthea21/pigment) - a KDE colorscheme helper

![](https://codeberg.org/amalthea21/pigment/raw/branch/master/doc/images/gui-screenshot.png)

- written in C++, using CMake
- pigment turns a theme template plus one or multiple palettes into KDE .colors files. instead of hard-coding colours, a theme references symbolic names (e.g. red, window_bg) and a palette assigns a value to these symbols
